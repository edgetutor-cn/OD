# OD 预习

Oxford Discover 1–6 配套课前预习。入口：https://edgetutor-cn.github.io/OD/

- 6 个级别，108 个单元，1,076 个核心词汇与短语，324 条配套编写句型练习。
- 1,389 个独立英语语音文件，单项播放、顺序播放、三档语速。
- 中文释义显隐、练习标记、完成状态、8 题单元词义自测。
- 980 张教材参考页按单元分组，按需加载与图片放大。
- 学习进度保存在当前浏览器；换设备不会自动同步。
- 课程入口沿用原密码。静态前端入口不属于账号认证系统。

## 本地运行

在本目录运行 `python -m http.server 8765`，浏览器打开 http://localhost:8765。不要直接双击 HTML。

## 部署

本目录为 GitHub Pages 静态站成品。保持 data 文件名大小写与引用一致；.nojekyll 不应删除。发布时上传本目录全部文件。

## 内容说明

词汇依据用户提供的飞书教材和本地对应 PDF 整理；句型跟读为按教材语法主题配套编写的示例。教材原页可在各单元“教材参考”中查阅。
